# IntelliJ IDEA & IDE Setup — THZ-LANG

This guide covers configuring IntelliJ IDEA for contributing to the THZ-LANG codebase.

---

## 1. Project Setup

1. **JDK Requirement:** Install Java 25 (GraalVM or OpenJDK 25).
2. **Gradle Import:** Open repository root in IntelliJ IDEA. The composite build will configure all 6 submodules.
