# Language Server Protocol & VS Code Extension — THZ-LANG

This document outlines the Language Server Protocol (LSP) implementation and the official VS Code extension for THZ-LANG.

---

## 1. LSP Features

- **Dual-Dialect Syntax Highlighting:** TextMate grammars supporting both `pt-BR` and `en-US` keywords.
- **Diagnostics & Contract Validation:** Real-time feedback for precondition/postcondition errors.
- **Code Completion & Hover:** Dynamic documentation of architectural metadata and standard library functions.
